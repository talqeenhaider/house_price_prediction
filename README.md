# 🏠 House Price Prediction using Machine Learning

An end-to-end Machine Learning project that predicts house prices using multiple regression algorithms. This project demonstrates data preprocessing, exploratory data analysis (EDA), model building, and performance evaluation.

# 🚀 Project Overview

The goal of this project is to build a predictive model that estimates house prices based on various features such as area, number of rooms, and other property-related factors.

# 🔍 Exploratory Data Analysis (EDA)
📦 Boxplots used to detect outliers in all features
📊 Scatter plots to understand relationships between house price and other variables
🔥 Correlation heatmap to analyze feature dependencies
# 🤖 Machine Learning Models

The following regression models were implemented:

Linear Regression
Decision Tree Regressor
Random Forest Regressor
# 📊 Model Performance
Model	R² Score
Linear Regression	0.716
Decision Tree	0.728
Random Forest	0.876 ✅
# 📈 Visualization
Scatter plots of Actual vs Predicted values
Helps in visually evaluating model accuracy and performance
# 🎯 Key Insights
✅ Random Forest performed best due to its ensemble learning approach
✅ Handling multicollinearity improved model stability
✅ Feature relationships significantly impact prediction accuracy
